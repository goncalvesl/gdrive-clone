Drive para Linux

Cliente independente para espelhar arquivos e pastas entre uma pasta local no Linux e uma pasta escolhida no Google Drive. Usa a API oficial do Google e executa a sincronização no computador do usuário.

O aplicativo oferece login pelo navegador, seleção de pasta, prévia de operações, histórico, pausa, conflitos preservados e recuperação local. É uma prévia para homologação; não é um produto oficial do Google.

Privacidade e acesso aos dados

Com autorização do usuário, o aplicativo solicita acesso ao Google Drive para listar, ler e sincronizar arquivos. Os dados de sincronização e as credenciais ficam no computador do usuário; o projeto não opera um servidor para receber os arquivos.
