Política de Privacidade

Esta política descreve como o Drive para Linux, cliente independente de código aberto mantido por Lucas Vilela de Souza Gonçalves, acessa e trata dados ao se conectar a uma conta Google. O aplicativo não é afiliado ao Google.

Dados acessados e permissão solicitada

Após a autorização no navegador, o aplicativo solicita o escopo https://www.googleapis.com/auth/drive, que permite visualizar e gerenciar arquivos do Google Drive. Essa permissão é mais ampla do que a pasta selecionada para espelhamento. O aplicativo usa a seleção do usuário para definir a raiz da sincronização, mas pode listar pastas de Meu Drive durante a escolha da raiz e consultar dados necessários à recuperação de operações.

O aplicativo pode acessar nomes, IDs, tipos, caminhos, tamanhos, versões e checksums de arquivos e pastas; conteúdo dos arquivos sincronizados; eventos de mudança; nome, e-mail e informações de armazenamento da conta. Ele também lê os arquivos da pasta local escolhida para comparar e sincronizar alterações.

Como os dados são usados

Os dados são usados para autenticar a conta, mostrar pastas e informações de armazenamento, planejar e executar o espelhamento bidirecional, detectar conflitos, retomar transferências e permitir recuperação após falhas. Conforme as opções e ações do usuário, o aplicativo pode criar, baixar, enviar, renomear, mover ou enviar arquivos à lixeira do Drive. A propagação de exclusões fica desativada por padrão.

Informações recebidas das APIs do Google são usadas somente para as funções visíveis do aplicativo. O projeto segue a Política de Dados de Usuários dos Serviços de API do Google, incluindo seus requisitos de Uso Limitado. Dados do Drive não são usados para publicidade, venda, pontuação de crédito ou treinamento de modelos de inteligência artificial.

Onde os dados ficam armazenados

O aplicativo funciona no computador Linux do usuário. A pasta local escolhida contém os arquivos sincronizados. Diretórios privados do aplicativo guardam configuração da conta e das pastas, IDs e metadados em SQLite, cursor de mudanças, histórico de operações, intenções pendentes, sessões de upload, arquivos temporários e cópias locais de recuperação. Os caminhos padrão são ~/.config/gdrive-clone e ~/.local/share/gdrive-clone, sujeitos às variáveis XDG do sistema.

O token de atualização OAuth é guardado no Secret Service (chaveiro) do Linux por meio de secret-tool. O token de acesso fica em memória durante o uso. Tokens não são gravados no banco SQLite. O caminho do arquivo de configuração do cliente OAuth pode ser salvo localmente.

Compartilhamento e transferência

O aplicativo se comunica diretamente com os serviços OAuth e Drive do Google por HTTPS para autenticação e operações solicitadas. Pode abrir no navegador links de documentos Google. Não existe servidor do projeto que receba conteúdo do Drive, nem telemetria ou anúncios embutidos. O mantenedor não acessa arquivos ou dados da conta por meio do aplicativo. Dados só chegarão ao mantenedor se o usuário os enviar voluntariamente em uma solicitação de suporte; não envie tokens nem arquivos pessoais em issues públicas.

O aplicativo não vende dados nem os compartilha com anunciantes ou corretores de dados. O Google trata os dados recebidos por seus serviços conforme suas próprias políticas.

Segurança, controle e exclusão

As conexões com as APIs do Google usam HTTPS; o login usa navegador, PKCE e retorno temporário em 127.0.0.1. Configuração e estado local usam diretórios e arquivos privados; a proteção final também depende do sistema e do chaveiro do usuário.

O comando Desconectar remove o token de atualização do chaveiro local, mas preserva configuração, banco de estado, arquivos sincronizados e cópias de recuperação. Para retirar a autorização da conta Google, o usuário também pode revogar o acesso nas conexões da Conta Google. Os dados locais permanecem até serem removidos pelo usuário; o aplicativo não apaga automaticamente cópias de recuperação. Arquivos mantidos no Drive seguem os controles da própria conta Google.

Alterações e contato

Alterações desta política serão publicadas nesta página. Se houver uma nova finalidade para dados do Google, ela deverá ser comunicada antes do uso correspondente. Dúvidas sobre privacidade podem ser enviadas para goncalvesl@gmail.com.
