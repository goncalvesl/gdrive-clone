# Contribuição

Comece pelo [AGENTS.md](../AGENTS.md). Entregue mudanças pequenas com problema, comportamento resultante e evidência de validação.

Para uma funcionalidade: vincule um ID de paridade; escreva ou ajuste o contrato; implemente no componente responsável; exponha pelo motor; teste o resultado e falhas relevantes; atualize lacunas e registro. Para mudança visual, inclua inspeção da interface renderizada quando houver UI.

Documente decisões duradouras em ADR com contexto, decisão, consequências e alternativas. Não escolha licença de distribuição sem decisão do proprietário; a licença do projeto ainda não foi definida. Registre dependências e recursos de terceiros quando forem incorporados. Os documentos deste repositório foram redigidos para este projeto, sem copiar os textos do PhotoCraft.

Não marque tarefas como concluídas com base em mocks quando o contrato exige API real. Registre explicitamente os checks não executados e o motivo.
