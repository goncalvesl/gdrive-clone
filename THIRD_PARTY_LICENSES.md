# Licenças das dependências

Inventário das declarações de licença das crates resolvidas por `Cargo.lock` para o alvo Linux x86_64. Cada dependência mantém sua licença; o texto e avisos próprios estão no pacote de origem indicado. Expressões `OR` representam alternativas declaradas pela dependência, não uma relicença pelo projeto. Gerado a partir de `cargo metadata --locked --format-version 1 --filter-platform x86_64-unknown-linux-gnu` em 2026-10-26.
